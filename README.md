# Agent 协作与交付规范

一份中文 [AGENTS.md](AGENTS.md)，供团队和编程 Agent 共用。它覆盖需求判断、产品与交互质量、Git 协作、集中测试、交付验收和模块交接。

## 使用

- **作为 Codex 全局规范**：将 [AGENTS.md](AGENTS.md) 放到 Codex 配置目录，默认是 `~/.codex/AGENTS.md`。已有同名文件时，按需合并条款。
- **作为项目规范**：把文件放到仓库根目录，按项目实际情况填写末尾的「项目适配信息」，记录主线分支、测试命令和发布流程等约定。
